# Todo CLI — Command Line Todo

Purpose

- Tiny CLI app to practice I/O, argument parsing, and packaging.

Tech stack (starter)

- Python (argparse) OR Node.js (commander)

Features

- add "task description"
- list
- complete <id>
- remove <id>

Quick start (Python)

1. python todo.py add "Buy milk"
2. python todo.py list

First issue

- Implement the `list` command and persist tasks to a local JSON file.
