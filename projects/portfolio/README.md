# Portfolio — Personal Website (starter)

Goal

- A clean, responsive static portfolio showcasing projects, contact info, and a short resume.

What you'll learn

- HTML, CSS, responsive design, hosting with GitHub Pages or Netlify.

Structure

- /index.html — landing page
- /projects/ — project listing pages or cards
- /about.md — short bio and contact

Quick start

1. Clone this repo
2. Open index.html in your browser

Deployment

- GitHub Pages: use the repo settings to serve from main branch / root
- Netlify: connect the repo and set build command (none for static)

First issue (good first task)

- Create a mobile-first responsive hero section with your name, tagline, and links to projects.
