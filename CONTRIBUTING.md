# Contributing

Thanks for visiting my profile! I’m a beginner and I welcome mentorship and small contributions.

How to contribute

1. Fork the repo and create a branch for your change.
2. Open a clear, focused pull request with a description of the change and why it helps.
3. If you are leaving feedback, please be kind — I’m learning.

Good first contributions

- Fix typos or clarify README sections
- Add a project demo or deploy instructions
- Add tests or CI for small projects

Code of Conduct

Be respectful and constructive. I will not tolerate harassment.
