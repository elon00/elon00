# Security Policy

## Scope

This repository primarily contains GitHub profile information, marketing documentation, and portfolio pointers. Security vulnerabilities in an individual protocol, app, contract, SDK, or service should be reported through the **affected project's** security advisory/disclosure process.

## Reporting

Please **do not disclose vulnerabilities in public issues or discussions**. Open the affected GitHub repository, choose **Security → Advisories → Report a vulnerability** if the feature is enabled, and include reproducible steps, affected versions/commits, threat impact, and suggested mitigation. If private reporting is unavailable, avoid posting exploit details publicly; contact the maintainers using a verified private contact method listed by that repository, if one exists.

For documentation errors or non-sensitive broken links, open an issue in this repository.

## Expectations

We welcome coordinated and responsible disclosures. This policy does **not** promise an SLA, bug bounty, independent audit, certification, or that every project is production-ready. The scope of support and remediation depends on the affected project.
